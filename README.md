# IMS Studio — صفحة خدمات التصوير والمونتاج وإدارة السوشيال ميديا

صفحة هبوط (Landing Page) عربية بالكامل (RTL) تعرض خدماتك كمصوّر إعلامي ومونتير
ومدير سوشيال ميديا، مع لوجو الشركة ونموذج تواصل بيبعت مباشرة على واتساب.

مبنية بـ HTML و CSS و JavaScript خام — من غير أي مكتبات أو خطوات بناء.
ارفعها على أي استضافة أو على GitHub Pages وهي تشتغل على طول.

---

## التشغيل محليًا

افتح `index.html` في المتصفح مباشرة، أو شغّل سيرفر بسيط:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

---

## هيكل الملفات

```
index.html              الصفحة كاملة (كل الأقسام والنصوص)
assets/css/style.css    التصميم والألوان والاستجابة للموبايل
assets/js/main.js       القائمة، الحركات، العدّاد، الفلاتر، إرسال واتساب
assets/img/logo.svg     لوجو الشركة (SVG قابل للتكبير بلا فقد جودة)
```

## التخصيص السريع

### 1) اسم الشركة
مكتوب في مكانين داخل `index.html` (الهيدر والفوتر) تحت الكلاس `brand`:

```html
<span class="brand__name" dir="ltr">IMS Studio</span>
<span class="brand__sub" dir="ltr">Videomaker</span>
```

غيّر كمان `<title>` ووصف الصفحة في `<meta name="description">`.

### 2) اللوجو
`assets/img/logo.svg` هو **إعادة رسم** لمونوجرام IMS Studio كـ SVG (عشان يفضل
حاد في أي مقاس ويشتغل كأيقونة للموقع). لو عايز ملف اللوجو الأصلي بالظبط:

1. حط الملف في `assets/img/logo.png`
2. غيّر المسار في 3 أماكن داخل `index.html`:
   - `<link rel="icon" href="...">`
   - `<img class="brand__mark" src="...">` في الهيدر
   - `<img class="brand__mark" src="...">` في الفوتر
   - وكمان `<meta property="og:image" content="...">` لو عايز يظهر في المشاركة

**ملاحظة:** يفضّل يكون الملف بخلفية شفافة (PNG) عشان يندمج مع خلفية الصفحة الداكنة.

### 3) بيانات التواصل
- الإيميل والتليفون: قسم `#contact` في `index.html`.
- **رقم الواتساب**: لازم يتغيّر في مكانين
  - `assets/js/main.js` → المتغير `WHATSAPP_NUMBER` (صيغة دولية بدون `+`، مثال: `201234567890`)
  - `index.html` → رابط الزر العائم `https://wa.me/966550798990`
- روابط السوشيال ميديا: الوسوم `<a class="social" href="#">` — بدّل `#` بروابطك.

### 4) الأعمال (البورتفوليو)
كل عمل عبارة عن `<figure class="shot">` جواها `<div class="shot__ph">` كخلفية
مؤقتة. استبدلها بصورك:

```html
<figure class="shot" data-cat="photo">
  <img src="assets/img/work-1.jpg" alt="وصف العمل" loading="lazy">
  <figcaption class="shot__cap"><strong>اسم المشروع</strong><span>اسم العميل</span></figcaption>
</figure>
```

قيم `data-cat` المتاحة: `photo` / `video` / `social` — وهي اللي بتشتغل عليها أزرار التصفية.

### 5) الألوان
كل ألوان الهوية متغيرات في أول `assets/css/style.css` تحت `:root` — غيّرهم مرة
واحدة وهيتطبقوا على الصفحة كلها:

```css
--accent:#4bb8c9;       /* اللون الأساسي — تركوازي مستمد من وهج العدسة في اللوجو */
--accent-soft:#9fe4ee;  /* درجة أفتح للعناوين الصغيرة */
--grad:linear-gradient(135deg,#a9e9f2,#4bb8c9 45%,#1f7d8e);
--bg:#08090b;           /* خلفية الصفحة */
```

لو عايز الهوية الذهبية بدل التركوازي، بدّل التلات متغيرات دي بـ
`#d9a441` و `#f7d488` و `linear-gradient(135deg,#f7d488,#d9a441 45%,#b3761f)`.

## المميزات

- تصميم داكن سينمائي مناسب لشغل التصوير والفيديو
- عربي بالكامل باتجاه RTL وخط Cairo
- متجاوب مع الموبايل والتابلت مع قائمة جانبية
- حركات ظهور عند التمرير وعدّاد أرقام للإحصائيات
- تصفية الأعمال حسب النوع
- نموذج تواصل بيحوّل البيانات لرسالة واتساب جاهزة
- زر واتساب عائم في كل الصفحة
- دعم `prefers-reduced-motion` وروابط تخطي وتباين مناسب لإمكانية الوصول
- وسوم Open Graph لمشاركة الصفحة على السوشيال ميديا
